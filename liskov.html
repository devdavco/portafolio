SOLID — Principio L

Liskov Substitution Principle

Una subclase debe poder usarse en cualquier lugar donde se espere su clase padre, sin romper el programa ni producir sorpresas.

La regla: si B extiende A, debes poder pasar un B donde se espera un A y todo debe seguir funcionando correctamente.

❌ Violación — Ave & Pinguino

Pinguino extiende Ave, pero anula volar() con un crash. Cualquier método que reciba un Ave y llame a volar() explotará en tiempo de ejecución si recibe un Pinguino.

Ave.java / Pinguino.java Viola LSP 
class Ave {
    public void volar() {
        System.out.println("Estoy volando");
    }
}

class Pinguino extends Ave {
    @Override
    public void volar() {
        // ❌ crash en tiempo de ejecución
        throw new RuntimeException("¡Los pingüinos no vuelan!");
    }
}

static void hacerVolar(Ave ave) {
    ave.volar(); // 💥 explota si ave es un Pinguino
}

hacerVolar(new Ave());      // ✅ "Estoy volando"
hacerVolar(new Pinguino()); // ❌ RuntimeException

El problema

El crash es una sorpresa en runtime — el compilador no avisa. Cualquier código que confíe en Ave se rompe silenciosamente.

✅ Solución — Rediseñar la jerarquía

Solo el comportamiento compartido va en Ave. El método volar() se extrae a una interfaz Volador — solo lo implementan las aves que realmente vuelan. Pinguino no promete lo que no puede cumplir.

Ave.java 
package animals;

public class Ave {
    public void comer() {
        System.out.println("Estoy comiendo");
    }
}
Volador.java 
package animals;

public interface Volador {
    void volar();
}
Aguila.java 
package animals;

public class Aguila extends Ave implements Volador {
    public void volar() {
        System.out.println("Estoy volando");
    }
}
Pinguino.java 
package animals;

public class Pinguino extends Ave {
    // no implementa Volador — no promete lo que no puede ✅
}
Main.java Correcto 
import animals.*;

public class Main {
    public static void main(String[] args) {
        Aguila   aguila   = new Aguila();
        Pinguino pinguino = new Pinguino();

        aguila.comer();    // "Estoy comiendo"
        pinguino.comer(); // "Estoy comiendo"

        hacerVolar(aguila);    // ✅ "Estoy volando"
        // hacerVolar(pinguino) → ❌ error de compilación
    }

    static void hacerVolar(Volador animal) {
        animal.volar();
    }
}

La solución

El error ahora es un error de compilación — detectado antes de correr el programa. Sin sorpresas, sin contratos rotos.

      ├── Ave.java

SOLID — Principle L

Liskov Substitution Principle

A subclass must be usable wherever its parent class is expected — without breaking the program or producing surprises.

The rule: if B extends A, you should be able to pass a B anywhere an A is expected and everything should still work correctly.

❌ Violation — Ave & Pinguino

A Pinguino extends Ave, but overrides volar() with a crash. Any method that receives an Ave and calls volar() will explode at runtime when handed a Pinguino.

❌ Violates LSP 
class Ave {
    public void volar() {
        System.out.println("Estoy volando");
    }
}

class Pinguino extends Ave {
    @Override
    public void volar() {
        // ❌ runtime crash — narrows the contract
        throw new RuntimeException("¡Los pingüinos no vuelan!");
    }
}

static void hacerVolar(Ave ave) {
    ave.volar(); // 💥 explodes when ave is a Pinguino
}

// Main
hacerVolar(new Ave());      // ✅ "Estoy volando"
hacerVolar(new Pinguino()); // ❌ RuntimeException

The problem

The crash is a runtime surprise — the compiler won't warn you. Any code trusting Ave is silently broken when a Pinguino slips in.

✅ Fix — Redesign the hierarchy

Move only shared behavior into Ave. Extract volar() into a Volador interface so only birds that actually fly implement it. Pinguino makes no promise it can't keep.

Ave.java 
package animals;

public class Ave {
    public void comer() {
        System.out.println("Estoy comiendo");
    }
}
Volador.java 
package animals;

public interface Volador {
    void volar();
}
Aguila.java 
package animals;

public class Aguila extends Ave implements Volador {
    public void volar() {
        System.out.println("Estoy volando");
    }
}
Pinguino.java 
package animals;

public class Pinguino extends Ave {
    // no implements Volador — makes no promise it can't keep ✅
}
✅ Main.java 
import animals.*;

public class Main {
    public static void main(String[] args) {
        Aguila  aguila   = new Aguila();
        Pinguino pinguino = new Pinguino();

        aguila.comer();    // "Estoy comiendo"
        pinguino.comer(); // "Estoy comiendo"

        hacerVolar(aguila);    // ✅ "Estoy volando"
        // hacerVolar(pinguino) → ❌ compiler error, caught before runtime
    }

    static void hacerVolar(Volador animal) {
        animal.volar();
    }
}

The fix

The error is now a compile-time error — caught before the program runs. No surprises, no broken contracts.

src/
  └── animals/
      ├── Volador.java   ← interface
      ├── Ave.java
